## Requirements
- `ENG-VAL-010` — Use one Project Validation Engine across Open, Save, Build, Collect and manual validation contexts.
- `ENG-VAL-011` — Represent findings as structured Problems with severity Error/Warning/Info and target/context data.
- `ENG-VAL-012` — Separate structural/schema, referential/semantic and resource/build validation concerns.
- `ENG-VAL-013` — Error block Build; Warning and Info do not.
- `ENG-VAL-014` — Validation report problems without silently modifying project data.
- `ENG-VAL-015` — Run fast/debounced validation after relevant edits and full validation for Open/manual/Collect/Build as appropriate.
- `ENG-VAL-016` — Detect broken entity references and invalid ownership/cycles where the data model forbids them.
- `ENG-VAL-017` — Detect missing runtime-required assets during full Build validation.
- `ENG-VAL-018` — Validate Widget props/dependencies through Widget Contract.
- `ENG-VAL-019` — Validate Component dependency cycles and pinned revision references.
- `ENG-VAL-020` — Validate Screen initialPageId and other required runtime entry points.
- `ENG-VAL-021` — Quick Fix, if added, remain explicit user action and MUST NOT be a prerequisite for validation correctness.
