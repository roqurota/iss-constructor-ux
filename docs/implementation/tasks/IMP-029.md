# IMP-029 — Widget registry and common runtime contract

- **Wave:** 4
- **Dependencies:** IMP-013, IMP-017, IMP-006
- **Allowed scope:** packages/widgets
- **Non-goal:** No public SDK.

## Requirements
- `ENG-WIDGET-012` — Initial architecture support Gallery, Image Viewer, Quiz, Form and Mini-game widget families.
- `ENG-WIDGET-001` — Every Widget declare stable `widgetType` and `widgetSchemaVersion`.
- `ENG-WIDGET-002` — Widget project-visible behavior integrate through registered Actions/Triggers.
- `ENG-WIDGET-003` — Widget asset dependencies be discoverable by Build.
- `ENG-WIDGET-004` — Dispose/cancel Widget-owned work on Page Leave.
- `ENG-WIDGET-005` — Permit project-authored arbitrary executable JavaScript as Widget props.
- `ENG-WIDGET-010` — Widget be a functional module with internal state/behavior and a declared customization contract.
- `ENG-WIDGET-011` — Widget need not expose all internals as ordinary Elements.
- `ENG-WIDGET-017` — Initial V2 expose a public third-party Widget SDK requirement.
