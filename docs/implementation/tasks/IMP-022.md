# IMP-022 — Screen Media Player core

- **Wave:** 4
- **Dependencies:** IMP-015, IMP-017, IMP-014, IMP-006
- **Allowed scope:** packages/media + runtime
- **Non-goal:** Single system player per Screen.

## Requirements
- `ENG-MEDIA-022` — Page navigation while Screen Media Player is active close/stop it using Media Exit semantics before/with Page transition as defined by runtime composition.
- `ENG-MEDIA-001` — Provide exactly one system fullscreen Screen Media Player per Screen.
- `ENG-MEDIA-002` — Keep Page media Elements separate from the system Screen Media Player.
- `ENG-MEDIA-005` — A new Play Content request supersedes stale pending preparation for older requested content on the same Screen Media Player.
- `ENG-MEDIA-010` — `Play Content` accept either a single Asset or first-class Playlist as content source.
- `ENG-MEDIA-019` — Screen Media Player support Play, Pause, Stop, Restart, Seek, Next/Previous Item, Volume and Mute/Unmute actions.
- `ENG-MEDIA-020` — Replacing currently playing content leave only the newest accepted content active.
- `ENG-MEDIA-021` — Old preparation completion MUST NOT steal playback after a newer content request.
- `ENG-MEDIA-023` — Natural content finish/Stop/Exit reveal the underlying current Page unless configured behavior navigates elsewhere.
- `ENG-MEDIA-031` — Screen Media Player prepare requested media before playback.
- `ENG-MEDIA-033` — Preparation be invalidatable on replacement/reset/lifecycle termination.
