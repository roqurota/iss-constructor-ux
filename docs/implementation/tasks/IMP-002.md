# IMP-002 — Canonical Project Model types and IDs

- **Wave:** 1
- **Dependencies:** IMP-001
- **Allowed scope:** packages/project-model
- **Non-goal:** Persistent/domain types only.

## Requirements
- `ENG-PROJ-001` — Treat `ProjectDocument` as the sole editable project source of truth.
- `ENG-PROJ-002` — Persist Editor UI state or Runtime state into `ProjectDocument` unless a future explicit requirement adds such persistence.
- `ENG-PROJ-003` — Use stable opaque IDs for independently referenceable entities; display names are not identity.
- `ENG-PROJ-004` — Save `.iss` atomically using temporary output, validation and replacement.
- `ENG-PROJ-005` — Perform explicit sequential forward migrations; older apps MUST refuse unsupported newer formats safely.
- `ENG-SCREEN-001` — Project support multiple logical Screens.
- `ENG-SCREEN-002` — Screen have stable ID, name, fixed width/height, Pages and one initialPageId.
- `ENG-SCREEN-003` — Screen width/height define orientation/aspect; no separate mandatory orientation flag is required.
- `ENG-SCREEN-004` — Every normal V2 Screen use the Page model; no Screenless special runtime path.
- `ENG-PAGE-001` — Page dimensions equal owning Screen resolution.
- `ENG-PAGE-002` — Page support navigation and scroll flow modes.
- `ENG-PAGE-003` — Long content be expressible with Scrollable Containers and/or sequential scroll composition without changing Screen resolution.
- `ENG-PAGE-004` — Page own ordinary Elements, Popups, optional Page Timeline, idle settings and Page lifecycle behaviors.
- `ENG-PAGE-005` — Screen persistent layer survive Page changes with per-Page visibility control.
- `ENG-ELEM-001` — Independently editable Elements have stable IDs and transforms including x/y/width/height/rotation/scale.
- `ENG-ELEM-002` — Elements support visibility, opacity, z-order and locking where applicable.
- `ENG-ELEM-003` — Container is a real parent owning child element IDs; ownership graph MUST be acyclic.
- `ENG-ELEM-004` — Base primitives include Text, Image, Button, Video and Container.
- `ENG-ELEM-005` — Button support text/visual styling/icon and Behavior bindings.
- `ENG-ELEM-006` — Text support font family, size, color and horizontal/vertical alignment.
- `ENG-ELEM-007` — Image/video support fit/crop behavior appropriate to media type.
- `ENG-ELEM-008` — Element references to project assets use assetId, not source filesystem path.
- `ENG-ELEM-009` — Layering and arbitrary positioning reproduce reference-case compositions.
