# IMP-028 — Component definitions, revisions and instances

- **Wave:** 4
- **Dependencies:** IMP-004, IMP-010
- **Allowed scope:** project-model + Constructor + runtime compile support
- **Non-goal:** Controlled propagation only.

## Requirements
- `ENG-CONSTR-033` — Component editing create a new revision rather than silently mutating all existing instances.
- `ENG-CONSTR-034` — Provide controlled Review & Apply Updates flow for component instances and preserve overrides by default.
- `ENG-COMP-001` — Component instances remain pinned to a revision until controlled update is applied.
- `ENG-COMP-002` — Instance overrides win by default during component update review.
- `ENG-COMP-003` — Silently propagate component changes over existing instance overrides.
- `ENG-COMP-010` — Component Definition store revision history with one current revision.
- `ENG-COMP-011` — Component Instance reference componentId and pinned revisionId.
- `ENG-COMP-012` — Saving edited Component Definition create a new revision.
- `ENG-COMP-013` — Existing instances remain on prior revision until explicit Review & Apply.
- `ENG-COMP-014` — Review identify affected instances and conflicts.
- `ENG-COMP-015` — Instance overrides remain authoritative by default on conflict.
- `ENG-COMP-016` — Detach materialize instance as independent local Elements and remove future component-update linkage.
- `ENG-COMP-017` — Nested Components be supported unless dependency cycle validation rejects a cycle.
