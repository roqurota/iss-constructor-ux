# IMP-053 — Multi-PC disconnect/reconnect fault tolerance

- **Wave:** 8
- **Dependencies:** IMP-052
- **Allowed scope:** distributed runtime
- **Non-goal:** Healthy nodes continue.

## Requirements
- `ENG-SYNC-004` — A disconnected Client after installation startup MUST NOT freeze unrelated healthy nodes indefinitely.
- `ENG-SYNC-019` — After installation is running, loss of one Client MUST NOT globally stop healthy nodes.
- `ENG-SYNC-020` — Actions targeted to unavailable node fail safely and appear in diagnostics.
- `ENG-SYNC-021` — Reconnected Client join future synchronized operations after clock sync; missed historical actions MUST NOT be automatically replayed.
- `ENG-SYNC-022` — Transparently synchronize ordinary Shared Player Variables across PCs in initial V2.
