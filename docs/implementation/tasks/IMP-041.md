# IMP-041 — TCP/UDP Network Service

- **Wave:** 6
- **Dependencies:** IMP-013
- **Allowed scope:** packages/network + Player Main
- **Non-goal:** No Multi-PC sync protocol.

## Requirements
- `ENG-NET-001` — Treat incoming TCP/UDP as Trigger sources and outgoing messages as Actions.
- `ENG-NET-002` — Unknown/unmatched network input fail safely and be diagnosable.
- `ENG-NET-010` — Central Player Network Service own configured TCP/UDP listeners.
- `ENG-NET-011` — Support multiple listening ports.
- `ENG-NET-012` — Network Trigger support Any/specific source IP and optional source-port filtering.
- `ENG-NET-013` — Initial payload matching support Exact, Starts With and Contains.
- `ENG-NET-014` — Require Regex matching in initial V2.
- `ENG-NET-015` — TCP listener support configurable framing with newline default and advanced fixed/raw modes.
- `ENG-NET-016` — UDP treat datagram payload as message without TCP framing.
- `ENG-NET-017` — One Network Trigger may execute multiple Actions including cross-Screen actions.
- `ENG-NET-018` — Support named outgoing Network Endpoints with transport/host/port/framing data.
