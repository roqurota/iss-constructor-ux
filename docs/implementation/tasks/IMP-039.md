# IMP-039 — Constructor Preview runtime

- **Wave:** 6
- **Dependencies:** IMP-037, IMP-017, IMP-022
- **Allowed scope:** apps/constructor preview
- **Non-goal:** Same runtime semantics as Player.

## Requirements
- `ENG-PREV-001` — Constructor Preview use the same Runtime Engine source/packages as Player.
- `ENG-PREV-002` — Preview compile a project snapshot through Runtime Compiler semantics before starting RuntimeSession.
- `ENG-PREV-003` — Preview execute real Actions, media, timelines, Widgets and TCP/UDP semantics.
- `ENG-PREV-004` — All Screens Simulator create real logical ScreenRuntimeSessions rendered scaled for inspection; scaling MUST NOT change logical project resolution.
- `ENG-PREV-006` — Developer overlay be outside project visual coordinate system.
- `ENG-PREV-007` — ESC may exit Developer Preview but production Player MUST NOT inherit this as default kiosk exit.
- `ENG-PREV-008` — Preview restart from a new snapshot rather than live-mutating active Runtime definition.
- `ENG-CONSTR-024` — Full Preview run same Runtime Engine semantics as Player.
- `ENG-CONSTR-025` — Preview support Physical Displays mode and All Screens Simulator mode.
- `ENG-CONSTR-026` — Preview snapshot project state; editing after preview start MUST NOT silently hot-mutate the active runtime session.
