# IMP-006 — Virtual Asset Library core

- **Wave:** 1
- **Dependencies:** IMP-002
- **Allowed scope:** project-model asset registry + asset service
- **Non-goal:** No Build packaging.

## Requirements
- `ENG-ASSET-001` — Asset Library be virtual and independent from physical source folder layout.
- `ENG-ASSET-002` — AssetRecord retain stable assetId, kind, sourcePath, metadata and optional virtual folder.
- `ENG-ASSET-003` — Virtual folder rename/move MUST NOT move original source files.
- `ENG-ASSET-004` — Missing source file preserve AssetRecord and references for relink.
- `ENG-ASSET-005` — Recognize at least project-supported image, video, audio, font, SVG and animation asset kinds.
- `ENG-ASSET-006` — Asset import allocate stable IDs and gather usable metadata without making source paths runtime identity.
- `ENG-FONT-001` — Project Fonts be explicit project resources.
- `ENG-FONT-002` — Build package required Project Fonts and Runtime load them from Build.
- `ENG-FONT-003` — System-installed fonts remain usable for compatibility, but portable Project Fonts are preferred.
