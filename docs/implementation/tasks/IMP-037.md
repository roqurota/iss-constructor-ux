# IMP-037 — Runtime Compiler

- **Wave:** 5
- **Dependencies:** IMP-002, IMP-005, IMP-006, IMP-028, IMP-029
- **Allowed scope:** build/compiler
- **Non-goal:** Authoring→RuntimeProject only.

## Requirements
- `ENG-BUILD-001` — Player consumes Build only and MUST NOT open `.iss`.
- `ENG-BUILD-002` — Build operate from a ProjectDocument snapshot.
- `ENG-BUILD-003` — Full validation occur before publish; required used missing assets are Build Errors.
- `ENG-BUILD-004` — Package only runtime-required asset dependencies.
- `ENG-BUILD-006` — Generate runtime `project.json` and `manifest.json`; authoring source paths MUST NOT be runtime dependencies.
- `ENG-BUILD-010` — Capture an immutable ProjectDocument snapshot at Build start.
- `ENG-BUILD-011` — Run full structural, referential, semantic and resource validation against that snapshot before compilation.
- `ENG-BUILD-013` — Discover runtime dependencies transitively from Screens, Pages, Elements, Widgets, Components, Playlists, fonts, system visuals and other compiled runtime entities.
- `ENG-BUILD-014` — Include only assets reachable from the runtime dependency graph; unused registered assets MUST NOT be required for Build success.
- `ENG-BUILD-015` — A missing source asset reachable from the runtime dependency graph is a Build Error.
- `ENG-BUILD-016` — Treat a missing unused registered asset as a Build-blocking error.
- `ENG-BUILD-017` — Compile authoring ProjectDocument into a separate RuntimeProject representation.
- `ENG-BUILD-018` — Copy authoring-only metadata such as Designer Canvas frame positions into RuntimeProject unless explicitly required at runtime.
- `ENG-BUILD-019` — Replace authoring asset source paths with Build-relative packaged asset paths.
- `ENG-BUILD-020` — Preserve stable assetId as runtime identity.
- `ENG-BUILD-021` — Materialize project fonts required by runtime into Build; Player MUST NOT depend on fonts being installed in Windows.
- `ENG-BUILD-022` — Compile Component instances from their pinned revisions and applied overrides; historical unused revisions need not ship to Player.
- `ENG-BUILD-023` — Ask each Widget Contract for declared asset dependencies.
- `ENG-BUILD-028` — Include Screen→Display mapping or Multi-PC topology in project.json.
