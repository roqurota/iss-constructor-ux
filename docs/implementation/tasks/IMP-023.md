# IMP-023 — Playlist engine

- **Wave:** 4
- **Dependencies:** IMP-022
- **Allowed scope:** packages/media
- **Non-goal:** Filesystem folder is import convenience, not identity.

## Requirements
- `ENG-MEDIA-011` — Playlist preserve explicit item order independent of filesystem order.
- `ENG-MEDIA-012` — Quick Import Folder may create a Playlist, but later filesystem changes MUST NOT silently redefine Playlist membership/order.
- `ENG-MEDIA-013` — Image playlist items support duration; Video items use natural duration unless range overrides apply.
- `ENG-MEDIA-014` — Video playlist items support volume, mute and playback range settings.
- `ENG-MEDIA-015` — Non-loop Playlist finish exit content after final item.
- `ENG-MEDIA-016` — Next/Previous at a non-loop boundary exit content according to approved V1-equivalent behavior.
- `ENG-MEDIA-017` — Looping Playlist cycle deterministically.
- `ENG-MEDIA-018` — Emit Started, Item Started, Item Finished and Finished media/playlist events where applicable.
- `ENG-MEDIA-032` — Playlist prepare current + next item where cheap/useful.
