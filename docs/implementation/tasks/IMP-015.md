- **Wave:** 3
- **Dependencies:** IMP-013, IMP-002
- **Allowed scope:** packages/runtime-engine
- **Non-goal:** No renderer-specific visuals.

## Requirements

- `ENG-RT-005` — Page Leave reset Screen or Shared Variables.
- `ENG-RT-006` — Ignore stale asynchronous completion from invalidated Page/media/runtime generations.

- `ENG-RT-011` — Maintain exactly one active PageRuntime per normal ScreenRuntimeSession.
- `ENG-RT-012` — Page Enter create fresh Page-local runtime state.
- `ENG-RT-013` — Page Enter fire lifecycle behavior and start eligible auto Page Timeline at 00:00.

- `ENG-RT-015` — Page Leave cancel Page-owned Behavior Flows and Delays.
- `ENG-RT-016` — Page Leave stop Page Timeline and Page-owned media/animations.
- `ENG-RT-017` — Page Leave destroy Page-local state.
- `ENG-RT-018` — Re-entering a Page create a fresh Page runtime.
- `ENG-RT-019` — `oncePerScreenSession` timeline flags survive Page re-entry and reset on Reset Screen/clean restart.
- `ENG-RT-020` — Navigation during an in-progress transition avoid duplicate Page runtimes/orphan transitions; the later accepted destination determines final state.
- `ENG-RT-026` — Reset Screen close media/popups, cancel owned work, reset Screen variables/once flags/idle/nav history/locks and enter initial Page.
- `ENG-RT-031` — A stale async callback carry/validate owner generation identity before mutating runtime.
