# IMP-035 — Screensaver and idle engine

- **Wave:** 5
- **Dependencies:** IMP-015, IMP-022, IMP-019
- **Allowed scope:** runtime idle/system visual
- **Non-goal:** No Page Leave/Enter on overlay.

## Requirements
- `ENG-IDLE-001` — Each Screen have at most one Screensaver system entity.
- `ENG-IDLE-002` — Screensaver support simple background/image/video/text/logo/animation visual composition.
- `ENG-IDLE-003` — Page define its idle timeout/behavior.
- `ENG-IDLE-004` — Relevant processed user/runtime activity reset idle timer according to runtime policy; raw unmatched network noise MUST NOT count as meaningful activity.
- `ENG-IDLE-005` — Screensaver capture user input while visible.
- `ENG-IDLE-006` — User input may hide Screensaver when configured; external Trigger MUST NOT automatically hide it unless behavior says so.
- `ENG-IDLE-007` — Entering Screensaver close active Page Popups and Screen Media Player as defined by canonical lifecycle while keeping underlying Page runtime alive.
- `ENG-RT-027` — Screensaver show/hide MUST NOT fire Page Leave/Enter.
- `ENG-RT-028` — Underlying Page Timeline continue beneath Screensaver and Screen Media Player unless explicitly paused/stopped.
