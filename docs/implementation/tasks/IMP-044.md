# IMP-044 — Physical display discovery and mapping

- **Wave:** 6
- **Dependencies:** IMP-043
- **Allowed scope:** Player Main + technician UI
- **Non-goal:** Mapping stays deployment-local.

## Requirements
- `ENG-PLAYER-015` — Detect physical Windows displays and expose resolution/position/scale/primary metadata needed for mapping.
- `ENG-PLAYER-016` — Allow max one logical Screen per physical Display and max one Display per logical Screen.
- `ENG-PLAYER-017` — Display Mapping changes be staged until Save.
- `ENG-PLAYER-018` — Applying saved mapping dynamically create/retain/close/reassign runtime windows where possible without mandatory whole-Player restart.
- `ENG-PLAYER-019` — Missing assigned physical Display leave other Screens running and MUST NOT silently remap.
- `ENG-PLAYER-020` — Provide Identify Displays and Rescan Displays technician functions.
- `ENG-DISP-001` — Runtime behavior targets logical Screen IDs, never physical Display IDs.
- `ENG-DISP-002` — Store Screen→Display mapping in PlayerLocalConfig, not ProjectDocument or Build.
- `ENG-DISP-003` — Never silently remap a missing physical display.
- `ENG-DISP-004` — Failure/unavailability of one Screen output MUST NOT intentionally stop healthy Screens.
